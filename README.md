# LimeStone
Limestone is a revision/iteration of Marksard's Rhymestone. You can see the original here: https://github.com/marksard/Keyboards/tree/master/rhymestone

Currently, there is no build guide, but feel free to make one and push to the repository if you want to!

You can find the firmware here: https://github.com/TwoSune/Rhymestone2-Firmware
